Conectar ao GitHub

Para salvar, a tela grava no repositório do site. Cada pessoa da equipe usa um token próprio, que fica guardado só neste aparelho.

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e marque o repositório do bazar.
  3. Em Permissions, dê Contents: Read and write.
  4. Gere o token e cole abaixo.

Conectado.
